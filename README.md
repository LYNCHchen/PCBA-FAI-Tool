# PCBA 首检确认工具

面向 SMT/PCBA 产线首件检验（FAI）的 Windows 桌面工具：上传 PCB 高清图片 + 导入有序坐标文件，通过三点对位（自动镜像/旋转/偏移/仿射纠正图片拉伸）后，按坐标顺序逐个目视确认并记录结果，支持导出带 NG 局部截图的 Excel 报表。

单文件免安装，双击即用（Windows 10/11 x64）。

## 功能特性

- **三点对位**：P1/P2/P3 分别选择位号（回车确认）后双击图片对应焊盘点，自动计算镜像、旋转、偏移及仿射变换，纠正图片拍摄变形/拉伸导致的点位偏移
- **有序逐个确认**：严格按坐标文件顺序，↑/↓ 方向键翻步并自动记为 OK，空格键标记 NG
- **坐标文件导入**：支持 txt / csv / xlsx，表头兼容多种表达（序号/位号/X/Y/角度等），默认第 2 行起为数据
- **项目续检**：.pba 工程文件保存图片+坐标+对位参数+进度，可导出后再导入继续确认
- **显示辅助**：丝印、中心十字（细线四角方框样式，可独立开关）、全点位标记可选显示/隐藏；亮度/对比度滑动条实时调节显示便于目视
- **搜索跳转**：按位号搜索，自动跳转到对应点位并将画面居中
- **导出报表**：XLSX 格式，NG 点位自动截取板子局部放大图插入对应表格行
- **登录权限**：admin/guest 两级账号（管理员可改密码、管理用户），数据存 exe 同目录 pcba_users.json

## 快速开始

1. 双击运行 `PCBA首检确认工具.exe`，默认管理员 admin / 123456，访客 guest / 0000
2. 「上传图片」选择 PCB 高清图
3. 「导入坐标」选择坐标文件（txt/csv/xlsx，按 序号、位号、X、Y、角度 列排序）
4. 「三点对位」：P1/P2/P3 各选一个位号回车确认，再双击图片上对应焊盘点
5. 用 ↑/↓ 逐个确认，空格标记 NG，完成后「导出报表」得到带截图的 XLSX

详细操作见《使用说明.md》。
